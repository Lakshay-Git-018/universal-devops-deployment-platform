# Universal DevOps Deployment Platform

## Project Overview
A reusable DevOps platform designed to automate
the deployment of a demo learning application.

## Objectives
- Linux environment setup
- Git version control
- Docker containerization
- CI/CD automation
- Local application deployment
- Application health monitoring

## Environment
- Ubuntu (WSL)
- Git
- Docker
- GitHub Actions

## Deployment
Local development environment.
